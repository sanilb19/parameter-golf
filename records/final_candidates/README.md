# Final Candidates

This folder holds promoted final-candidate snapshots for possible submission.

Use it for:

- one subfolder per promoted candidate
- a short candidate README with the hypothesis and why it earned promotion
- any copied config, script, or artifact files needed to reconstruct the candidate quickly

Recommended naming:

- `YYYY-MM-DD_short_candidate_name`

Keep `index.tsv` updated whenever a new overnight winner is promoted here.
